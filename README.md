# Eerie Tapes (Forge 1.20.1)

Страшные кассеты в духе Mandela Catalogue.
Сборка: GitHub → вкладка Actions → последний запуск → Artifacts → eerietapes-jar.
Готовый .jar кладётся в папку mods (нужен Forge 1.20.1).

Команды для теста (нужны права оператора): /tape start house, /tape start forest, /tape stop
